# Qualitative + quantitative prompt sweep (Omni-MATH-Rule)

Generated by `scripts/summarize_quant_qual_sweep.py` from `evaluation/output/qualitative_quantitative_sweep/*/cautious_metrics.json`. Do not edit by hand — re-run the script.

Each cell was graded with `evaluation/math_eval_cautious.py`. **Abst** is `num_abstained / num_total`; **Sel acc** is `num_correct / num_attempted`; **Δ** is Sel acc minus that model's no-consequence anchor (the `standard` prompt run in `evaluation/output/baselines/<slug>/`). For quantitative cells, **Score/n** is the score the model actually banked under the rubric it was shown, per problem.

`r_0 = (s_c, s_a, s_i) = (+1, 0, 0)` is the no-consequence quantitative baseline added for the rebuttal: abstention is offered, but a wrong answer is free. It separates *"the model ignores how severe the penalty is"* from *"the model ignores whether there is a penalty at all"* — the distinction Reviewers 27Kr and LswH both asked about. Compare each model's r_0 row against its r_1 … r_100 rows: if abstention is flat from r_0 onward, the model is not responding to the existence of a penalty, let alone its magnitude.
